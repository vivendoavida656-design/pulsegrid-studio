🔄 Sincronização em Tempo Real (Vercel + Sócio)

Esta ferramenta já sincroniza instantaneamente entre abas locais e salva automaticamente. Para você e seu sócio verem as marcações ao vivo em dispositivos diferentes pela Vercel, conecte um banco gratuito do Firebase Realtime Database em 1 minuto:

1. Acesse console.firebase.google.com → Criar Projeto
2. Menu "Build" → Realtime Database → Criar Banco (Modo Teste)
3. Copie a URL do banco (ex: https://seu-app-default-rtdb.firebaseio.com)
4. Cole abaixo e clique em Conectar. Envie o link gerado para seu sócio!
